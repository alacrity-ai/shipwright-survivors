# Fire Rendering & FX System

This document describes the **procedural fire rendering pipeline** used in the unified WebGL2 renderer. The system is composed of:

1. **`FirePass.ts`** – GPU instanced renderer for all fire blobs.
    
2. **`FireManager.ts`** – SOA-based CPU-side simulation and event-driven emission manager.
    
3. **Gradient Ramp Atlas (`createGradientRampAtlas.ts`)** – Precomputed color ramps for different flame styles.
    
4. **`SpecialFxReporter.ts`** – Event-based helpers for standardized emission patterns.
    
5. Integration with **`UnifiedSceneRendererGL.ts`**, where the `FireSOA` is passed to `FirePass`.
    

---

## 1. FirePass (GPU Renderer)

Located in:  
`src/rendering/unified/passes/fx/FirePass.ts`

### Responsibilities

- Renders thousands of flame quads (up to 8,192) in a **single instanced draw call**.
    
- Uses **SOA (Structure of Arrays)** data for zero-GC packing of instance attributes.
    
- Supports procedural flicker/turbulence in shaders using `uTime`.
    
- Uses a **gradient ramp atlas texture** to color flames dynamically.
    
- Blends additively (`SRC_ALPHA, ONE`) for glowing effects.
    

### Constructor Signature

```
new FirePass(
  gl: WebGL2RenderingContext,
  cameraUBO: WebGLBuffer,
  fireRampTex: WebGLTexture, // Precomputed gradient atlas
  rampCount: number          // Number of ramps in the atlas
)

```

The `fireRampTex` and `rampCount` are generated by `createFireGradientAtlas`.

### Core Method

```
renderSOA(fireData: FireSOA, time: number): void

```

- Packs all fields (position, radius, age, intensity, rampIndex) into a flat interleaved buffer.
    
- Uploads to GPU and issues one `drawArraysInstanced` for all active flames.
    
- Automatically binds `uColorRamp` texture and `uRampCount` uniforms for shader-based lookups.

## 2. FireManager (CPU Simulation)

Located in:  
`src/systems/fx/FireManager.ts`

### Responsibilities

- Manages all active flames using a **packed SOA layout** (`x`, `y`, `radius`, `age`, `life`, `intensity`, `rampIndex`).
    
- **Recycles indices** for efficient memory use (no GC churn).
    
- Hooks into the **`GlobalEventBus`** to react to `'fx:fire:emit'` events.
    
- Optionally **spawns and updates dynamic point lights** for visual brightness.
    

### Event Handling

Upon construction, the `FireManager` registers:

```
GlobalEventBus.on('fx:fire:emit', (payload) => { ... });

```

Payload supports:

```
{
  x: number; y: number;
  radius?: number; life?: number; intensity?: number;
  rampIndex?: number;
  randomizeRadius?: boolean; randomizeLife?: boolean;
  count?: number;
  light?: boolean;
  lightRadiusScalar?: number;
  lightIntensity?: number;
  color?: string;
}

```

Each event spawns `count` blobs via `emitFire`.

### Lifecycle

- `update(dt)` advances ages, reduces remaining life, and removes expired blobs.
    
- Lights follow their associated flame until the flame is recycled.
    
- `getFireSOA()` provides the packed dataset for `FirePass`.

## 3. Gradient Ramp Atlas

Located in:  
`src/rendering/unified/utils/createGradientRampAtlas.ts`

### Responsibilities

- Builds a **single 2D texture** containing all gradient ramps.
    
- Each row represents one ramp (3 stops per ramp, 256 horizontal samples).
    
- Used by `FirePass` for smooth color lookups.
    

### Predefined Ramps

Defined in `FIRE_GRADIENT_RAMPS`:

1. Classic orange flame (`black → orange → white`)
    
2. Acid/poison green
    
3. Plasma/blue flame
    
4. Magenta/magic fire
    

Helper for initialization:

```
const { texture: fireRampTex, count: fireRampCount } =
  createFireGradientAtlas(gl);
this.firePass = new FirePass(gl, cameraUBO, fireRampTex, fireRampCount);

```

## 4. SpecialFxReporter (Event Helpers)

Located in:  
`src/core/interfaces/events/SpecialFxReporter.ts`

### Responsibilities

- Provides a **unified API** for emitting fire via the event bus.
    
- Exposes low-level `emitFire()` and several prefab variants:
    
    - `emitDefaultFlames(x, y, count)`
        
    - `emitBlueFlames(x, y, count)`
        
    - `emitPoisonFlames(x, y, count)`
        
    - `emitBigExplosionFlames(x, y, count)`
        

Each prefab:

- Configures default radius, lifetime, intensity, and `rampIndex`.
    
- Automatically **attaches dynamic point lights** to the flames for visual realism.
    

---

## 5. Integration in UnifiedSceneRendererGL

- `FireManager` is registered as a fixed updatable (updated every frame).
    
- `FireSOA` from `fireManager.getFireSOA()` is passed into:
    

```
this.firePass.renderSOA(fireSOA, dt);

```

after `LightningPass` in the unified rendering sequence.
